# JEE Performance Tracker

Flask + SQLite + SQLAlchemy + Jinja2 + vanilla JavaScript + Chart.js.

## Run
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

Run tests:
```bash
python -m pytest
```

Use **Load demo data** to populate the dashboard.
